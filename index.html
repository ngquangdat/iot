AESL0213C Controller

Nordic nRF52811 · e-paper 2.13" 250×128 · Web Bluetooth

Chưa kết nối
Trình duyệt này không hỗ trợ Web Bluetooth. Hãy dùng Chrome / Edge trên máy tính hoặc Android (trên iOS dùng ứng dụng Bluefy), và mở trang qua HTTPS.

Chế độ hiển thị

Mỗi lần chuyển chế độ, trang sẽ đồng bộ luôn giờ hiện tại của máy. Ở chế độ Đồng hồ, bấm lại để đổi kiểu mặt đồng hồ.

Thời gian

Lịch ngủ màn hình

Đồng hồ vẫn chạy nhưng màn hình ngừng refresh trong khoảng này để tiết kiệm pin (ví dụ 23:00 → 07:00).

Chưa đọc lịch.

Xem trước đúng 250×128 điểm ảnh và 3 màu thật của màn. Kéo trên hình để di chuyển ảnh hoặc chữ.

    Tuyến đường

    Google Maps API key

    Key chỉ được lưu trong trình duyệt của bạn, không đưa lên GitHub. Trong Google Cloud hãy bật Routes API và giới hạn key: Website restrictions = https://ngquangdat.github.io/*, API restrictions = Routes API.

    Cập nhật lên nhãn

    Với firmware gốc, mỗi lần gửi là một lần refresh 3 màu (~15–20 giây), nên web chỉ gửi khi sang hướng rẽ mới hoặc khi vượt các mốc 2 km, 1 km, 500 m, 300 m, 150 m, 50 m. Với firmware AESL0213C mới (có nav=1), web chỉ gửi lệnh nhỏ và nhãn tự vẽ, cập nhật mỗi vài giây.

    Kích hoạt

    Một số firmware bị khóa cho tới khi kích hoạt. Kiểm tra trước; nếu firmware kiểu "legacy" báo locked, mã được tính từ 4 ký tự hex cuối của tên Bluetooth.
